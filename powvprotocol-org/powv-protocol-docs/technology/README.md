# Technology

PoWV uses a layered cyber-physical trust architecture to convert physical events into independently verifiable digital evidence.

This section covers the protocol architecture, compact evidence format, and connectivity model used between edge infrastructure and the verification layer.

## In this section

* **Architecture** — the end-to-end trust model.
* **Compact Evidence** — deterministic evidence for constrained environments.
* **Industrial Connectivity** — communication across industrial and satellite links.
